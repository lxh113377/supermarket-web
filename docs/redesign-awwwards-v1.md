# 超柿 · 日常鲜活所｜视觉初版设计

> 2026-10-25 · 分支 redesign/awwwards-v1
> 范围：超市顾客端与经营管理端。校园打印是独立上游应用，不在这一轮改写；不改 API、D1、支付、密钥与部署。

## 设计判断

### 视觉主张
一张会呼吸的校园市集海报：奶白纸、深松绿、番茄橙，真实商品摄影与有秩序的中文大字并置。

### 内容结构
1. 首屏：品牌 → 购物承诺 → 主行动 → 商品陈列。
2. 服务：按生活/娱乐/学习/其他提供明确的入口，保留原分类 ID。
3. 选品：固定品牌头 + 分类导航 + 商品画廊 + 既有加购与购物车。
4. 购买：既有详情、购物车、确认、支付路由，统一字体/颜色/间距。
5. 经营：深松绿侧栏 + 宽工作面 + 明确的内容标题；商品继续原行正下方内联编辑。

### 动效主张
首屏分段入场、主图轻微滚动位移、悬停时图片/箭头清晰反馈；所有位移与循环都尊重 prefers-reduced-motion。

## 调色与排版

- 纸 #F6F4EC，墨绿 #183C31，番茄 #ED6847，酸橙 #DBE995。
- 主标题：中文粗黑、紧凑字距；拉丁和数字沿用自托管 Bricolage Grotesque。
- 正文：中文原生可读字体，正文颜色对比 ≥4.5:1；不大面积使用低透明度小字。
- 以细分隔线、空间、局部圆角区分内容，不堆白卡与阴影。

## 方案取舍

- 采用：真实页面构图与组件重塑，保留原 hooks/API 与路由。
- 否决：只换 CSS 颜色和字体；它保留旧首页的中央窄栏与后台模板感。
- 回滚：所有改动只在独立 Git 分支；不 push、不合并、不部署。主分支 main 原样保留。

## 初版验收

- 可截图：1440 桌面、390 手机、768 平板的首页/商城/后台。
- 键盘：语义链接、按钮、可见焦点、tablist 方向键不丢失。
- 行为：营业时间/打烊文案、分类链接、加购数量、购物车金额与商品内联编辑保持。
- 动效：减少动效模式不出现持续滚动或视差，信息不丢。
- 工程：npm run typecheck、lint、build、verify:backend、npm test；关键浏览器流程零横向溢出、零运行错误。

## 非目标

不宣称获得 Awwwards/Webby/FWA 奖项；这些是设计质量参照而非已获认证。本轮优先可感知的视觉初版，不把未经视觉验收的全站工作宣称为最终完成。
