# 超柿 · 色块编辑式｜视觉重构 v3 设计说明

> 2026-10-25 · 分支 `redesign/awwwards-v2`（基于 `main` 的 8a908b1 新开，未触碰原分支）
> 范围：顾客端全部页面（首页/商城/分类/服务表单/商品详情/购物车/确认/支付/成功/查询/AI 导购/404）与经营端全部页签（看板/商品/订单/服务/评价 + 登录墙）。
> 校园打印（public/print）为独立上游应用，不在本轮改写；不改 API、D1、密钥、部署与数据结构。

## 0. 一句话主张

把老大给的三色卡**直接做成版式**：整幅色块横带（深褐黑首屏 → 森林绿门帘 → 黄铜金细节）与暖纸留白交替，像一张被裁成网页的色卡。昼是「白昼的铺子」，夜是「夜里亮灯的铺子」——同一套色相，两副面孔。

## 1. 八维设计决策

### 1.1 配色（严格以配色卡为准）
- 色相唯一来源：深褐黑 #2A221D / 森林绿 #1F4A39 / 黄铜金 #B18739。所有 ramp 由这三个锚点的色相派生，不引入第四个色相族（支付微信绿/支付宝蓝为品牌外必需色，取深档保 AA）。
- 双主题：语义槽（--t-*，RGB 三通道）承载「昼=暖纸/夜=深褐」的对偶；色块横带两主题恒定（木料与门帘不随昼夜换色）。切换只换槽值，类名与 DOM 零改动。
- 默认昼。理由：① 白昼是主使用时段；② 仓库既有渲染级判据（layout.spec 暖白页底钉值、chartOptions 白卡对比度对账）以昼面为基准，默认昼 = 判据零漂移；③ 夜主题完整保留 v1/v2 的暗面气质，作为可切换的第二面孔（页头/工作台顶栏均有切换钮，localStorage 持久化，首帧无闪变）。
- 对比度全部实算：昼正文 15.9:1、次级 4.7:1、价格金 4.6:1；夜正文 14.4:1、次级 6.1:1、亮金 7.7:1；黄铜实底配深褐字 4.98:1（两主题同值）。恒定色带上的字用字面量类（.on-brass/.cover-band/.float-cart 等），不随语义槽翻转。

### 1.2 排版
- 中西文搭配：拉丁/数字 = 自托管 Bricolage Grotesque（可变字重，价格 tabular-nums）；中文标题 = 自托管思源宋体 Black 子集（922 字 CJK，215KB woff2，fontTools 按源码字符集裁剪），正文 = 苹方/雅黑系统栈。宋体黑字重的中文刊头 +  grotesque 数字，是本站的字体识别符。
- 字号阶梯：display-xl clamp(44→72px)/display-lg/display-md/正文 14-15px/微文案 ≥12px（移动端换行中文正文一律 ≥12px，prose-readability 闸）；eyebrow 10px 全大写宽字距只用于色带内的标签。
- 行高：正文 1.9-2.0（中文长行），微文案 1.6，标题 1.08-1.36。

### 1.3 留白节奏
- 首页三段式：褐黑首屏（min 740px）→ 暖纸服务区（上下 80-128px 大留白 + 目录行 96px 行高）→ 森林绿门帘（72-104px）。带与带之间零圆角、零阴影，靠色块与 1px 金线分层。
- 商城/后台：刊头下 28px 金线分隔；卡片间距 12-20px 网格；后台工作区 max-width 1460px 居中。

### 1.4 视觉层级
- 每页恰好一个 h1（heading-structure 闸）；窄屏商城刊头从 sr-only 改为可见紧凑标题（v1 遗留缺陷修复）。
- 层级靠「色块 > 字号 > 字重 > 金线」四级：色带定区块，字号定主次，字重定强调，1px 渐变金线定分隔（不用灰粗线、不靠阴影堆卡）。

### 1.5 动效与微交互
- 入场：首屏五段 stagger（50-400ms，cubic-bezier(0.16,1,0.3,1)）；拍立得三卡各自旋转落位。
- 悬停：目录行整行点亮 + 箭头斜移；拍立得图片 scale(1.06)+rotate(-1deg)；按钮高光扫过。
- 按压：全站 :active 反馈（scale 0.9-0.98 或背景反馈），press-feedback 闸零缺失。
- 滚动：首屏展台 0.1 视差（仅桌面、尊重 reduced-motion）。
- 铁律：曲线只用在册四条、时长全部 50ms 网格（motion-consistency 闸）；prefers-reduced-motion 全量降级且信息不丢。

### 1.6 响应式
- 断点 370/767/900/1180/1500：手机单列+吸底购物条、平板三列、桌面四列+左分类栏；后台手机变顶部滑轨页签。
- 320px 无横向溢出（design-shots 报告 overflowX=0 全绿）。

### 1.7 原创性
- 识别符三件：① 色块横带版式（配色卡即版式）；② 发光暖台上的拍立得商品图（multiply 混入板色）；③ 宋体黑字重中文刊头 + Bricolage 数字。
- 反模板：无三等分卡片行、无紫渐变、无玻璃拟态堆砌；空态/404 用同一套切角柿块语言。

### 1.8 工程与可回滚
- 全部改动在 `redesign/awwwards-v2` 分支；不 push、不合并、不部署。回滚 = 切回 main。
- 不动数据结构/接口/路由/hooks 语义；仅 className 与样式层 + 两个纯展示组件（ThemeToggle/useTheme）。
- 构建/lint/typecheck/单测/视觉闸全绿为交付门槛（见 §3）。
