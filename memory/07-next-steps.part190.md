# 07 分卷 190 —— 第 91 轮：八维台账增量与下一轮候选

> CHANGELOG 同日条目为准；本卷是 part189 的续卷（同轮拆两卷守 4KB 铁限）。

## 八维台账增量（第 91 轮）

- 动效：飞点从「隐形 + 每帧重排」改成 transform/opacity 合成层；**JS 驱动的位移必须在源头判
  reduced-motion**（CSS 全局压制管不到 transform 补间，CustomerPage 用 matchMedia 决定挂不挂载）。
  支付页等待从「呼吸点 + 一句话」升级成真的在走的秒针：「几秒前」由秒针 effect 推进，
  只在轮询回调里 setState 会让它在两次轮询之间冻住 = 假读数。
- 配色：票据纸色 #f2ecdf（13 处字面量）入册 `--t-paper` —— 站内两种「白」不再一个有名分一个随手漂；
  `.step-done` 从微信品牌绿 #15803d 回到锚点森林绿（第三方品牌色只该活在「微信支付」那一个钮上）；
  `#7fc48f` 回到 `--t-green-400`（重复字面量）。
- 原创性：emoji 图形（✅ ⚠️）换本站铜印 / 自绘 IconAlert / 暖台牌托；EmptyState 的通用灰方块
  换成与货架、灯箱**同一块暖台** —— 「空着」与「有货」共用一块台，读起来是柜台暂时空而不是坏了。
- 层级：详情页「口味：」从 16px/700（副信息压 20px h1）降到 meta 档，且保持单个文本节点
  （三处用例按整串 getByText 定位）。
- 死选择器：`.market-shop .fixed[ref]` 三条覆写**从未命中**（React 的 ref 不落成 HTML 属性）
  ⇒ 换 `[data-cart-dock]` 并在 CustomerPage 两处挂上，吸底购物条的直角/深绿底第一次真的生效。
- 断点对齐：MarketHero 窄档判定 767→900，与 CSS 藏第三件拍立得同一个数 —— 旧写法在 768–900px
  渲染三件而 CSS 只藏到 767 ⇒ 该区间第三件「存在但不可见」。登记册同步补两行含此依据。
- 子页面廉价感（用户点名项）本轮清掉四处洼地：确认页（左底稿 + 右实时票据双栏，凑单做成铜轨）、
  首页（第四带「今日货架」把 65 件真实在售抬到首屏）、评价区（星级五条账本可点筛）、
  支付页（问店心跳）。全部零新接口、零新色相。
