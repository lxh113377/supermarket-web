# 07 分卷 101 —— 第五十四轮踩坑两条（自主卷分卷 97 逐字迁出）

## 踩坑（本轮自己的两条）

1. **`-s` 不是本机 `gh api` 的参数**：第一版存在性探测写成 `gh api -s --jq ...`，五个仓全部报 usage 错 ⇒ 空输出 ⇒
   脚本按「空即缺失」打出「五个参照仓都没有 .editorconfig」。**这是一条我自己造的假 0**（零命中未证输入非空）。
   改成按**逐仓退出码**判存在后结论立刻翻转（2/5 有）。同族：任何 0 命中都要先证明这条命令能命中已知存在的东西。
2. **`node -e` 里带反斜杠的模式串被 bash 改写**：`p.includes('images')` 那类反斜杠转义落成 `\images\` ⇒ SyntaxError。
   与户内「反斜杠控制字符」同族：跨 shell 传含反斜杠的 JS 一律先落成文件再跑。
