## 指针判据的一个陷阱（与上两节同类：判据自身被绕过）

- **标题里不许出现下一个轮号**：erify:pointers 的 P1 把「节标题里的轮号」当轮次声明读 ——
  本轮把下一个轮号写成二级标题，指针当场报「内层已到第 N 轮」并连带 P2 判红；
  反过来，一个标题里写两个轮号（第六十六/六十七轮）也会让 P1 少读一个轮次。
  ⇒ 轮号只许在正文与指针里出现，**标题恰好声明一个**。
