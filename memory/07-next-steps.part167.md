# 07-next-steps.part167 — 第七十五轮自咬四（外层报告自指行）

## 自咬四（第七十五轮，外层报告）：提交信息说「改掉了自指行」，实际那行还带着 sha

- 形态：我把 §7.5 那行从「1 件待提交」改成「…推上远端（`3b7b6ab`）」，然后用一条写着「去掉自指行 —— 报告里不写本行所在文件的提交号」的提交信息
  把**带着 3b7b6ab 的那一行**提交了（前一步脚本在语法解析期就报错，替换分支整段没跑；我的替换分支判断报了 `MISS both` 却仍然 commit）。
- 这就是本仓判据一直防的形态：**信息宣称的处置与实际内容不符**（第六十六轮 §9「待实测回填却标本轮已做」同族，只是这次发生在外层散文里，没有 delivery-claims 覆盖）。
- 修法：正则替换该行 + **改完立刻回读文件确认 sha 不在文里**，而不是相信分支逻辑的返回值。现已确认 `3b7b6ab` 不在报告里，
  该行只答 P5 判的「归档面 dirty 0 件」。
- 口径新增：**凡「改文件 + 提交信息描述该改动」的动作，必须回读文件内容核对，不看脚本返回值。** 纯 docs/散文面的自指无法靠判据兜住，只能靠这条动作纪律。
