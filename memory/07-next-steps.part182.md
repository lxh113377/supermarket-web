## 2026-10-25 — 三页改造的测试撞点三条（改 UI 前先对表）

1. **金额/编号类文本是高频撞点**：同一笔钱全站显示多处（主价/参数表/摘要/合计行），
   任何一处新增独立文本叶子都会撞 getAllByText 计数或 getByText 单数断言。
   对策已验证两形：① 金额整串一个节点（cart-ticket-amount）；② 算式形态
   「3 × ¥2.66 = ¥7.98」整串（qty-total，textContent 不等于任何既有串）。
2. **价签类角标同理**：「No.33」必须连体一个 <b>，拆成 <i>No.</i><b>33</b> 会撞
   getByText(/^33$/)（详情页参数表「目录编号 33」的既有断言）。
3. **JSX 注释位置**：{cond && ( /* 注释 */ <div/> )} 语法错（表达式位置不收 JSX 注释），
   注释必须放 && 括号外 —— CartPage 顶栏与票脚两次同坑，每次都是 tsc 当场拦下。
